# All visualization modes on both renderers.
#
# Every mode is run on the rasterizer and on the ray tracer, including the modes that only
# carry meaning for one of them (8/9 blas are ray tracing, 11 discrete lod is rasterization):
# an inapplicable mode has to stay harmless, not fail the pipeline build.
#
# The tail adds the DLSS variants. DLSS changes the shader permutation
# (USE_DLSS x ALLOW_SHADING x USE_DEPTH_ONLY), and visualize 0 / 2 / 10 are exactly the three
# modes that select the three distinct combinations, so those are the ones repeated with DLSS on.

SEQUENCE "raster_visualize_00_shaded"
# --sequenceframes only exists once the sequencer is initialized, so it cannot be
# passed on the command line - it has to be set here, in the first sequence.
--sequenceframes 32
--sequenceresetframes 8
--renderer 0
--dlss 0
--swraster 0
--culling 1
--twopassculling 1
--discretelod 1
--visualize 0
