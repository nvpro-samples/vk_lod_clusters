# Rasterization: the culling / two pass culling / discrete lod matrix.
#
# Run over both geometry layouts for the same reason as seq_raytrace_blas.txt: discrete lod
# only triggers for instances that sit on a single fully resident lod level, so how the
# geometries are shared across the grid changes which instances qualify.
#
# Two pass culling is only meaningful with culling enabled; the off/on combination is kept
# in the matrix anyway, it has to be a no-op rather than a failure.
#
# Visualization is pinned to "discrete lod" so the screenshots of one block are comparable.

SEQUENCE "raster_unique0_cull_off_twopass_off_discrete_off"

# passed on the command line - it has to be set here, in the first sequence.

--sequenceresetframes 8
--renderer 0
--dlss 0
--swraster 0
--gridunique 0
--streaming 1
--culling 0
